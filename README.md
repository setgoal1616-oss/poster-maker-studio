# Bengali AI Poster Creator

বাংলা YouTube Shorts Poster তৈরি করার জন্য একটি সহজ ওয়েবসাইট।

## 1. Website কীভাবে চালাবেন

1. `bengali_text_poster_maker_free_text_position.html` ফাইল Download করুন।
2. Android-এর File Manager খুলুন।
3. HTML ফাইলটি খুঁজে বের করুন।
4. Chrome Browser দিয়ে Open করুন।
5. এখন Poster তৈরি করতে পারবেন।

## 2. Background Features

- নিজের Background Image Upload করুন।
- Preview-এর মধ্যে এক আঙুল দিয়ে Drag করে Background সরান।
- দুই আঙুল দিয়ে Pinch করে Zoom In / Zoom Out করুন।
- Background Lock / Unlock করুন।

## 3. Headline & Main Text

- Preview থেকে Headline Drag করুন।
- Main Text Drag করুন।
- নিজের পছন্দমতো Position ঠিক করুন।
- Text Size পরিবর্তন করুন।
- Text Color পরিবর্তন করুন।
- Text Alignment পরিবর্তন করুন।

## 4. Select Text Feature

1. Select Text ON করুন।
2. Preview থেকে নির্দিষ্ট শব্দ বা বাক্য Select করুন।
3. Text Color নির্বাচন করুন।
4. Font Size নির্বাচন করুন।
5. Apply to Selected Text Only চাপুন।

## 5. Export

- Poster Preview দেখুন।
- Text Position ঠিক করুন।
- Background Adjust করুন।
- Export / Download অপশন ব্যবহার করুন।

## 6. Important

- মূল HTML ফাইলের নাম পরিবর্তন করবেন না।
- HTML ফাইলটি Chrome Browser দিয়ে চালাবেন।
- README ফাইলটি Website চালানোর জন্য বাধ্যতামূলক নয়।
